# Джарвис — краткое руководство

Джарвис — голосовой помощник, который живёт на вашем компьютере. Скажите **«Джарвис»** — и он ответит, выполнит
команду или поможет разобраться с тем, что на экране. Подробности об установке, настройках и решении проблем — в
[README](../README.md).

## 1. Установка

**macOS** (13 Ventura и новее): откройте `Jarvis-…-mac-arm64.dmg` (Apple Silicon) или `…-mac-x64.dmg` (Intel) и
перетащите Jarvis в «Программы». Первый запуск: правой кнопкой по Jarvis → **«Открыть»** → «Открыть». В macOS 15 и
новее: Системные настройки → Конфиденциальность и безопасность → **«Всё равно открыть»**.

**Windows** (10/11, 64-бит): запустите `Jarvis-Setup-…-win-x64.exe`. Если появится «Система Windows защитила ваш
компьютер» — **«Подробнее»** → **«Выполнить в любом случае»**. Выберите «Только для меня» и нажмите «Установить».

## 2. Первые шаги

1. Получите ключ OpenAI на <https://platform.openai.com/api-keys> (на счёте должен быть положительный баланс).
2. В Джарвисе откройте **Настройки → ИИ**, вставьте ключ, нажмите **«Сохранить»** и **«Проверить подключение»**.
3. Разрешите доступ к **микрофону**. На macOS для скриншотов и управления компьютером также понадобятся
   **Запись экрана**, **Универсальный доступ** и **Автоматизация** — Джарвис попросит их сам, а вкладка
   **Настройки → Управление ПК** покажет, что ещё не выдано.
4. Скажите: **«Джарвис, привет!»**

Джарвис работает в фоне: закрытое окно не выключает его. Значок-«реактор» в строке меню (macOS) или в трее (Windows)
открывает меню: Открыть, Слушать, Голосовая активация, Модель по умолчанию, Настройки, Выход. Когда Джарвис слушает,
значок становится «заполненным» (на Windows — ярко-голубым).

## 3. Как разговаривать с Джарвисом

| Способ | Как |
|---|---|
| Голосом | «Джарвис, …» одной фразой — или «Джарвис», сигнал, затем команда |
| Без слова активации | **Cmd+Shift+Space** (macOS) / **Ctrl+Shift+Space** (Windows), затем говорите |
| Окно чатов | **Cmd+Shift+J** / **Ctrl+Shift+J** или щелчок по значку |
| Текстом | напишите в чате; Enter — отправить, Shift+Enter — новая строка |

- После ответа Джарвис ещё несколько секунд слушает — можно сразу уточнить без «Джарвис».
- Чтобы перебить Джарвиса, скажите «Джарвис» — он замолчит и выслушает вас.
- В окне чата можно прикрепить картинку, вставить скриншот кнопкой **«Скриншот»** или надиктовать текст микрофоном.

## 4. Что можно попросить

- «Сделай скриншот экрана и скажи ответ по каждому из тестов»
- «Открой Telegram» · «Закрой Safari» · «Переключись на Chrome»
- «Громкость 40 процентов» · «Выключи звук» · «Следующий трек»
- «Напомни через 15 минут выключить чайник» · «Какие у меня напоминания?»
- «Найди в интернете рецепт бешбармака» · «Какая погода в Алматы?»
- «Открой папку Загрузки» · «Что лежит на рабочем столе?»
- «Напечатай: перезвоню через час» · «Заблокируй компьютер»

Опасные действия (перезагрузка, выключение, принудительное закрытие программ, перезапись файлов, команды терминала)
Джарвис выполнит только после вашего подтверждения.

## 5. Модели: Luna, Terra, Sol

- **Luna** — самая быстрая и экономная: короткие вопросы и команды.
- **Terra** — баланс (по умолчанию): большинство задач.
- **Sol** — самая умная: сложные задачи, код, тесты и документы со скриншота.

Переключатель моделей есть в шапке каждого чата; модели по умолчанию — в **Настройки → ИИ**. Режим **«Авто»**
сам выбирает самую новую доступную вашему ключу версию (например, GPT-6 вместо GPT-5.6).

## 6. Голос

**Настройки → Голос**:
- **OpenAI** — голос в стиле Джарвиса (спокойный британский дворецкий), можно сменить голос и скорость.
- **ElevenLabs** — любой голос из вашей библиотеки ElevenLabs: вставьте API-ключ ElevenLabs, выберите голос из
  списка или вставьте его Voice ID. Используйте только голоса, на которые у вас есть права.
- **Системный** — встроенные голоса компьютера, работают без интернета.

Кнопка **«Прослушать»** позволяет проверить голос. Озвучивание ответов: на голосовые запросы, всегда или никогда.

## 7. Конфиденциальность в двух словах

- Слово «Джарвис» по умолчанию распознаётся **прямо на компьютере**; в облако уходит только ваша команда после него.
- Скриншоты делаются только по вашей просьбе.
- История чатов и настройки хранятся у вас на компьютере; ключи — в зашифрованном виде.
- Управление компьютером можно выключить: **Настройки → Управление ПК**.

## 8. Если что-то не работает

- **Не откликается на «Джарвис»** — проверьте микрофон (Настройки → Активация: индикатор уровня должен двигаться),
  включите «Голосовая активация» в меню значка, попробуйте горячую клавишу.
- **Ошибка про ключ или баланс** — проверьте ключ в Настройки → ИИ и баланс на platform.openai.com.
- **macOS: скриншот чёрный** — включите Jarvis в «Запись экрана» и перезапустите его.
- **macOS: не нажимаются клавиши** — включите Jarvis в «Универсальный доступ» (после обновления — удалите из
  списка и добавьте снова).
- **Нет голоса** — нажмите «Прослушать» в Настройки → Голос; для проверки выберите системный голос.

Полный список решений — в разделе «Решение проблем» [README](../README.md#решение-проблем).
