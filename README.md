# Джарвис (Jarvis)

**Голосовой ИИ-помощник для macOS и Windows.** Живёт в фоне (значок в строке меню / в трее), откликается на слово
**«Джарвис»**, отвечает голосом в стиле невозмутимого британского ИИ-дворецкого и умеет управлять компьютером:
делать скриншоты и разбирать тесты на экране, открывать программы, менять громкость, ставить напоминания, искать в
интернете и многое другое. Все разговоры сохраняются в чатах с историей.

> Голос Джарвиса — это **стиль** (спокойный бархатный баритон, вежливость, лёгкая ирония), заданный инструкциями для
> синтеза речи. Приложение не копирует и не имитирует голос реального актёра.

## Возможности

- **Всегда рядом.** Работает в фоне, запускается вместе с системой. Закрытие окна не выключает Джарвиса — он остаётся
  в строке меню (macOS) или в области уведомлений (Windows).
- **«Джарвис, …»** — скажите имя и команду одной фразой или сначала «Джарвис», а затем команду. Слово активации
  по умолчанию распознаётся **локально** на вашем компьютере.
- **Отвечает голосом** — голоса OpenAI в стиле Джарвиса, любой голос из вашей библиотеки **ElevenLabs** или
  встроенные системные голоса (работают офлайн).
- **Чаты с историей** — все голосовые и текстовые разговоры сохраняются, их можно искать, переименовывать и удалять.
  Сообщения с Markdown, кодом, таблицами и скриншотами.
- **Три уровня интеллекта: Luna, Terra, Sol** — выбираются в настройках или прямо в шапке чата.
- **Управление компьютером голосом**: скриншот экрана и ответы на вопросы теста, открыть / закрыть / переключить
  приложение, громкость и музыка, напоминания, поиск в интернете, файлы и папки, ввод текста, нажатие клавиш, мышь,
  блокировка и сон, команды терминала (с подтверждением).
- **Мини-панель (HUD)** с анимированным «реактором» показывает, что Джарвис слушает, думает или говорит.
- **Безопасность**: опасные действия (перезагрузка, выключение, принудительное закрытие, перезапись файлов,
  команды терминала) выполняются только после вашего подтверждения.

## Установка на macOS

Нужна macOS 13 Ventura или новее. Выберите файл под ваш процессор:

| Mac | Файл |
|---|---|
| Apple Silicon (M1, M2, M3, M4 …) | `Jarvis-1.0.0-mac-arm64.dmg` |
| Intel | `Jarvis-1.0.0-mac-x64.dmg` |

(Узнать процессор: меню Apple → «Об этом Mac» → строка «Чип» или «Процессор».) Вместо `.dmg` можно взять `.zip` с теми же
суффиксами — внутри то же приложение.

1. Откройте `.dmg` и перетащите **Jarvis** в папку **«Программы»** (Applications).
2. **Первый запуск.** Приложение не подписано сертификатом Apple Developer, поэтому macOS не откроет его двойным
   щелчком. Сделайте так:
   - **macOS 14 и старше:** в Finder откройте «Программы», нажмите на **Jarvis** правой кнопкой мыши (или с
     зажатой Control) → **«Открыть»** → в диалоге снова **«Открыть»**.
   - **macOS 15 Sequoia и новее:** запустите Jarvis один раз (появится предупреждение — нажмите «Готово»), затем
     откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз до раздела
     «Безопасность» и нажмите **«Всё равно открыть»** (Open Anyway) напротив сообщения о Jarvis, подтвердите паролем.
   - Если macOS пишет, что приложение «повреждено», снимите карантин командой в Терминале и запустите снова:
     ```bash
     xattr -dr com.apple.quarantine /Applications/Jarvis.app
     ```
   Это нужно сделать только один раз.
3. **Разрешения.** Джарвис попросит их при первом использовании соответствующей функции. Если вы нажали «Не
   разрешать» или запрос не появился, включите Jarvis вручную:

| Разрешение | Зачем | Где включить |
|---|---|---|
| **Микрофон** | слышать «Джарвис» и команды | Системные настройки → Конфиденциальность и безопасность → **Микрофон** → Jarvis |
| **Запись экрана** | скриншоты («что на экране», тесты) | Системные настройки → Конфиденциальность и безопасность → **Запись экрана и системного звука** (в macOS 13–14: **Запись экрана**) → Jarvis, затем перезапустите Jarvis |
| **Универсальный доступ** | нажатие клавиш, ввод текста, мышь | Системные настройки → Конфиденциальность и безопасность → **Универсальный доступ** → Jarvis (если его нет в списке — «+» → Программы → Jarvis) |
| **Автоматизация** | громкость, музыка, закрытие приложений | Системные настройки → Конфиденциальность и безопасность → **Автоматизация** → Jarvis → включите «System Events», «Music» и другие приложения |
| **Уведомления** | напоминания | Системные настройки → **Уведомления** → Jarvis → «Разрешить уведомления» |
| **Файлы и папки** | читать и открывать файлы по вашей просьбе | Системные настройки → Конфиденциальность и безопасность → **Файлы и папки** → Jarvis |

В приложении есть вкладка **Настройки → Управление ПК**: там видно состояние разрешений и есть кнопки
«Разрешить» / «Открыть настройки».

> **После обновления Jarvis** macOS может «забыть» выданные разрешения (у неподписанных приложений меняется подпись).
> Если скриншоты или управление клавиатурой перестали работать — в соответствующем списке выключите и снова включите
> Jarvis, а лучше удалите его кнопкой «−» и добавьте заново. Сбросить все разрешения разом:
> `tccutil reset All com.pomoshnik.jarvis`.

## Установка на Windows

Нужна 64-битная Windows 10 или 11. Скачайте `Jarvis-Setup-1.0.0-win-x64.exe` и запустите.

1. **SmartScreen.** Установщик не подписан сертификатом, поэтому Windows покажет «Система Windows защитила ваш
   компьютер». Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
2. Установщик говорит по-русски (или по-английски, если Windows не русская). Выберите **«Только для меня»** (не нужны
   права администратора), при желании измените папку установки и нажмите «Установить». Ярлыки появятся на рабочем
   столе и в меню «Пуск», после установки Джарвис запустится сам.
3. **Микрофон:** **Параметры → Конфиденциальность и защита → Микрофон** (в Windows 10: Параметры →
   Конфиденциальность → Микрофон) — включите **«Доступ к микрофону»**, **«Разрешить приложениям доступ к
   микрофону»** и **«Разрешить классическим приложениям доступ к микрофону»**.
4. **Уведомления** (для напоминаний): Параметры → Система → Уведомления → Jarvis.
5. Значок Джарвиса может спрятаться в скрытые значки трея (стрелка ^ возле часов). Перетащите его на панель задач,
   чтобы он всегда был виден, или включите его в Параметры → Персонализация → Панель задач → Другие значки панели задач.

Удаление: **Параметры → Приложения → Установленные приложения → Jarvis → Удалить**. Чаты и настройки остаются в
`%APPDATA%\Jarvis` — удалите эту папку вручную, если хотите стереть всё.

## Первый запуск: ключ OpenAI

Джарвис думает с помощью моделей OpenAI — нужен ваш API-ключ (оплата по факту использования, отдельно от подписки
ChatGPT).

1. Войдите на <https://platform.openai.com> и пополните баланс:
   <https://platform.openai.com/settings/organization/billing/overview>.
2. Откройте <https://platform.openai.com/api-keys> → **Create new secret key** → скопируйте ключ (`sk-…`). Ключ
   показывается один раз.
3. В Джарвисе: **Настройки → ИИ** → вставьте ключ → **«Сохранить»** → **«Проверить подключение»**. Должно появиться
   «Подключение работает. Доступно моделей: N».

Ключ хранится зашифрованным (Связка ключей macOS / DPAPI Windows через Electron `safeStorage`) и не передаётся
никуда, кроме OpenAI. В интерфейсе видна только маска вида `sk-…a1B2`.

Если вы работаете через корпоративный прокси или совместимый с OpenAI сервер, укажите его адрес в поле **Base URL**
(Настройки → ИИ).

## Модели Luna, Terra и Sol

Джарвис использует три уровня моделей OpenAI семейств **GPT-5.6 / GPT-6**:

| Уровень | Характер | Когда выбирать |
|---|---|---|
| ☾ **Luna** — быстрая | самая быстрая и экономичная | короткие вопросы, команды компьютеру, черновики |
| ◉ **Terra** — сбалансированная (по умолчанию) | баланс скорости и качества | большинство задач и голосовых команд |
| ☀ **Sol** — максимальная | флагман | сложные рассуждения, код, анализ, разбор тестов и документов со скриншота |

- **Где выбрать:** переключатель **Luna / Terra / Sol** в шапке каждого чата (действует на этот чат), а также в
  **Настройки → ИИ**: «Модель по умолчанию» для новых чатов и отдельно «Модель для голоса». Быстро сменить модель по
  умолчанию можно и из меню значка Джарвиса.
- **«Авто (новейшая)»** — режим по умолчанию. Джарвис смотрит, какие модели доступны вашему ключу, и для каждого
  уровня берёт самую новую версию вида `gpt-<версия>-<уровень>`: например, если доступна `gpt-6-sol`, она будет
  выбрана вместо `gpt-5.6-sol`. Если список моделей получить нельзя (нет ключа, нет сети), используются
  `gpt-5.6-luna`, `gpt-5.6-terra`, `gpt-5.6-sol`. Наведите курсор на переключатель в чате — увидите точный id модели.
- Для каждого уровня можно вручную указать конкретную модель и **уровень рассуждений** (от «Без рассуждений» до
  «Максимальный»). Чем выше — тем умнее, но медленнее и дороже.
- **Поиск в интернете** (Настройки → ИИ) позволяет модели отвечать на вопросы о погоде, новостях и курсах.

## Голос Джарвиса

**Настройки → Голос → Провайдер.** Кнопка **«Прослушать»** есть у каждого варианта.

### OpenAI (по умолчанию)

Голос `onyx` (низкий мужской) с инструкцией стиля «спокойный, утончённый британский ИИ-дворецкий». Можно выбрать
другой голос (`ash`, `echo`, `fable`, `cedar`, `marin` …), изменить скорость и текст инструкции стиля; кнопка
**«Стиль Джарвиса»** возвращает исходный стиль. Инструкции стиля поддерживает модель `gpt-4o-mini-tts`
(`tts-1` / `tts-1-hd` их игнорируют).

### ElevenLabs — любой голос из вашей библиотеки

1. Зарегистрируйтесь на <https://elevenlabs.io>. Откройте раздел **API Keys** (меню Developers / Settings → API Keys)
   → **Create API Key**. Если ключ ограничен по правам, разрешите **Text to Speech** и чтение **Voices**. Скопируйте
   ключ.
2. В Джарвисе: **Настройки → Голос → Провайдер: ElevenLabs** → вставьте ключ → **«Сохранить»**.
3. Выберите голос:
   - Откройте **Voice Library** (<https://elevenlabs.io/app/voice-library>) и подберите голос — удобно фильтровать по
     языку (Russian / English), полу, акценту (British) и назначению (Narration, Characters). Нажмите **«Add to My
     Voices»**. После этого голос появится в выпадающем списке Джарвиса (обновите список).
   - Или скопируйте **Voice ID**: в разделе **My Voices** откройте меню голоса (⋯) → **Copy Voice ID** и вставьте ID
     в поле **«Voice ID»** в Джарвисе.
4. Модель: **Multilingual v2** — лучшее качество русской речи, **v3** — самая выразительная, **Flash v2.5** —
   минимальная задержка, **Turbo v2.5** — быстро и качественно. Ползунки «Стабильность» и «Сходство» меняют
   характер голоса.

> **Права на голос.** Используйте только голоса, на которые у вас есть права: голоса из библиотеки ElevenLabs на
> условиях сервиса, свой собственный голос или голос человека, давшего согласие. Не клонируйте голоса актёров и
> других людей без разрешения. Сам Джарвис голоса не клонирует.

На бесплатном тарифе ElevenLabs месячный лимит символов невелик; когда он закончится, Джарвис сообщит «Лимит
ElevenLabs исчерпан» — переключитесь на OpenAI или системный голос.

### Системный голос (офлайн)

Голоса операционной системы: бесплатно и без интернета (сам ИИ при этом всё равно работает через OpenAI).
Качественные русские голоса нужно один раз скачать:

- **macOS:** Системные настройки → Универсальный доступ → Устный контент → Системный голос → **Управлять голосами…**
  → Русский → Milena / Yuri (лучше версии «улучшенное качество»).
- **Windows:** Параметры → Время и язык → Речь → **Добавить голоса** → Русский (Irina, Pavel).

### Когда Джарвис говорит вслух

**Настройки → Голос → «Озвучивать ответы»**: только на голосовые запросы (по умолчанию), всегда или никогда. Длинные
ответы озвучиваются частично («Остальное — в чате, сэр»), лимит меняется там же. Любое сообщение можно
прослушать кнопкой озвучивания под ним в чате.

## Голосовая активация

- Скажите **«Джарвис, открой Telegram»** — одной фразой. Или скажите **«Джарвис»**, дождитесь сигнала (или ответа
  «Да, сэр?») и в течение ~8 секунд произнесите команду.
- **Горячие клавиши** (меняются в Настройки → Активация):

  | Действие | macOS | Windows |
  |---|---|---|
  | Слушать команду сразу, без слова «Джарвис» | **⌘ Cmd + ⇧ Shift + Space** | **Ctrl + Shift + Space** |
  | Показать / скрыть окно Джарвиса | **⌘ Cmd + ⇧ Shift + J** | **Ctrl + Shift + J** |

- **Продолжение разговора.** После ответа Джарвис ещё ~6 секунд слушает без слова активации — можно сразу
  уточнить: «а теперь сделай громче».
- **Перебить.** Пока Джарвис говорит, скажите «Джарвис» — он замолчит и выслушает новую команду.
- **Движок распознавания слова «Джарвис»** (Настройки → Активация):
  - **Локально** (по умолчанию) — небольшая модель Whisper работает прямо на компьютере; звук никуда не уходит, пока
    не прозвучало «Джарвис».
  - **Облако** — фрагменты речи распознаёт OpenAI: точнее в шумной обстановке, но расходует трафик и баланс.
  - **Выключено** — только горячая клавиша и кнопка микрофона.
- Там же: свои варианты имени (по умолчанию «джарвис» и «jarvis»), чувствительность, время ожидания команды,
  выбор микрофона с индикатором уровня. Голосовую активацию можно быстро включить и выключить в меню значка
  Джарвиса или кнопкой-индикатором внизу списка чатов.

## Примеры команд

**Экран и тесты**
- «Джарвис, сделай скриншот экрана и скажи ответ по каждому из тестов» — Джарвис снимет экран (свои окна он прячет)
  и ответит по порядку: «Вопрос 1 — B: … коротко почему». Полный разбор — в чате.
- «Что у меня на экране?», «Переведи текст на экране», «Найди ошибку в коде на экране».

**Приложения**
- «Открой Telegram», «Запусти калькулятор», «Закрой Safari», «Переключись на Chrome», «Какие программы открыты?»

**Звук и музыка**
- «Громкость 30 процентов», «Сделай погромче», «Выключи звук», «Пауза», «Следующий трек».

**Напоминания**
- «Напомни через 10 минут проверить духовку», «Напомни завтра в 9 утра позвонить маме», «Какие у меня напоминания?»,
  «Отмени напоминание про духовку». Напоминания переживают перезапуск: Джарвис покажет уведомление и скажет его вслух.

**Интернет**
- «Найди в интернете рецепт плова», «Найди в Яндексе билеты в Астану», «Открой youtube.com»,
  «Какая погода сейчас в Алматы?», «Какой курс доллара?»

**Файлы и ввод**
- «Открой папку Загрузки», «Что лежит на рабочем столе?», «Прочитай файл заметки.txt на рабочем столе»,
  «Создай на рабочем столе файл список.txt с покупками: хлеб, молоко».
- «Напечатай: буду через пять минут», «Нажми Cmd+Shift+4», «Скопируй в буфер обмена мой адрес».

**Система**
- «Заблокируй компьютер», «Переведи в сон», «Сколько свободного места на диске?», «Сколько заряда у батареи?»,
  «Перезагрузи компьютер» (спросит подтверждение), «Запусти в терминале `brew update`» (покажет команду и
  спросит подтверждение).

## Конфиденциальность

- **Микрофон.** В режиме «Локально» звук анализируется только на вашем компьютере. В облако (OpenAI) отправляется лишь
  фрагмент речи **после** слова «Джарвис» (или после горячей клавиши) — чтобы точно распознать команду. В режиме
  «Облако» в OpenAI уходят все фрагменты речи, которые услышал микрофон.
- **Скриншоты** делаются только по вашей просьбе (или когда это нужно для вашей команды) и отправляются модели вместе
  с запросом. Копии хранятся локально в истории чатов.
- **Что уходит в OpenAI:** текст ваших запросов и история текущего чата, скриншоты и изображения, аудио команды для
  распознавания, текст ответов для озвучивания. Запросы идут с параметром `store: false`. По умолчанию OpenAI не
  обучает модели на данных API (см. политику OpenAI).
- **ElevenLabs** получает только текст ответов, если выбран этот провайдер голоса.
- **Где хранятся данные:** macOS — `~/Library/Application Support/Jarvis`, Windows — `%APPDATA%\Jarvis` (чаты,
  настройки, снимки, напоминания, журналы `logs/`). Ключи API — в зашифрованном виде; в журналы они не пишутся.
- **Управление компьютером** можно полностью выключить (Настройки → Управление ПК) — останутся только безопасные
  функции (время, сведения о системе, напоминания). Там же отключаются команды терминала и подтверждения.

## Решение проблем

| Проблема | Что сделать |
|---|---|
| Джарвис не откликается на имя | Проверьте, что голосовая активация включена (меню значка → «Голосовая активация ✓»), выдан доступ к микрофону и выбран правильный микрофон (Настройки → Активация — индикатор уровня должен двигаться). Произносите «Джарвис» в начале фразы. Попробуйте чувствительность «Высокая» или движок «Облако». Горячая клавиша работает всегда. |
| «Не задан API-ключ OpenAI» | Настройки → ИИ → вставьте ключ → «Сохранить». |
| Ошибка 401 | Ключ неверный или отозван — создайте новый. |
| «Недостаточно средств» / 429 insufficient_quota | Пополните баланс OpenAI. Обычный 429 (слишком много запросов) проходит сам через несколько секунд. |
| Ошибка 403 / регион не поддерживается | API OpenAI недоступен из вашей сети — используйте поле Base URL с совместимым сервером. |
| «Модель … недоступна для вашего ключа» | Выберите «Авто (новейшая)» или другую модель в Настройки → ИИ. |
| Нет звука ответа | Проверьте провайдера голоса и кнопку «Прослушать». Для проверки переключитесь на системный голос. Убедитесь, что «Озвучивать ответы» не выключено. |
| macOS: скриншот чёрный или только обои | Включите «Запись экрана» для Jarvis и **перезапустите** Jarvis. |
| macOS: не работают клавиши, ввод текста, мышь | Включите «Универсальный доступ». После обновления приложения удалите Jarvis из списка («−») и добавьте снова. |
| macOS: не меняется громкость / не закрываются приложения | Конфиденциальность и безопасность → Автоматизация → Jarvis → включите нужные приложения. |
| macOS: «приложение повреждено» | `xattr -dr com.apple.quarantine /Applications/Jarvis.app` |
| macOS: запрос «Jarvis хочет использовать конфиденциальную информацию из «Jarvis Safe Storage»» | Это Связка ключей, где Джарвис хранит зашифрованные ключи API. Введите пароль Mac и нажмите **«Разрешать всегда»** (после обновления приложения запрос может появиться снова). |
| Windows: SmartScreen блокирует установку | «Подробнее» → «Выполнить в любом случае». |
| Windows: антивирус ругается на PowerShell | Джарвис управляет системой через PowerShell-скрипты; добавьте папку Jarvis в исключения антивируса. |
| Горячая клавиша не срабатывает | Её занимает другая программа — назначьте другую в Настройки → Активация. |
| Джарвис не запускается вместе с системой | Настройки → Общие → «Запускать при входе в систему». |
| Всё сломалось | Настройки → Общие → «Сбросить настройки». Полный сброс — закройте Jarvis и удалите папку с данными (см. «Конфиденциальность»). |

Журналы для отчёта об ошибке: папка `logs` внутри папки данных (ключи в журналы не попадают).

## Сборка из исходников

Требуется **Node.js 22+** (рекомендуется 24) и npm. Нативных модулей нет, поэтому установщик Windows собирается и на
Mac (кросс-сборка), а `.dmg` — только на macOS.

```bash
npm install
npm run assets        # скачать модели (VAD, onnxruntime-web, Whisper) и сгенерировать иконки
npm run dev           # запуск в режиме разработки
npm run typecheck     # проверка типов
npm test              # юнит-тесты (Vitest)
npm run test:e2e      # сборка + сквозные тесты настоящего приложения (Playwright + mock OpenAI/ElevenLabs)
npm run dist:mac      # → release/Jarvis-<версия>-mac-arm64.dmg / .zip и …-mac-x64.dmg / .zip
npm run dist:win      # → release/Jarvis-Setup-<версия>-win-x64.exe
```

- **Сквозные тесты** (`tests/e2e/run.mjs`, только macOS: фразы для «микрофона» синтезирует `say`) запускают собранное
  приложение с отдельной папкой данных, локальным mock-сервером OpenAI/ElevenLabs и виртуальным микрофоном Chromium
  (настоящий микрофон, экран и системные разрешения не используются, звук выключен). Отдельные сценарии:
  `node tests/e2e/run.mjs --only S1,S3`; скриншоты и журналы — `--artifacts <папка>`, сохранить папки данных — `--keep`.
- В терминале VS Code задана переменная `ELECTRON_RUN_AS_NODE=1` — снимите её перед запуском Electron:
  `env -u ELECTRON_RUN_AS_NODE npm run dev` (PowerShell: `Remove-Item Env:ELECTRON_RUN_AS_NODE`).
- Собрать только под свой Mac быстрее: `npm run build && npx electron-builder --mac --arm64`.
- **Иконки** рисуются кодом: `node scripts/gen-icons.mjs` создаёт `build/icon.png|icns|ico` и значки трея в
  `resources/tray/`. С флагом `--preview <папка>` дополнительно сохраняет увеличенные превью всех размеров.
- **Подпись.** macOS-сборка подписывается ad-hoc (`identity: '-'` в `electron-builder.yml`) — этого достаточно для
  запуска на Apple Silicon. Для распространения без предупреждений нужен сертификат Developer ID и нотаризация
  (поля `mac.identity` и `mac.notarize`). Для Windows можно передать сертификат через переменные `CSC_LINK` /
  `CSC_KEY_PASSWORD`.
- **Переменные окружения для отладки:** `JARVIS_USER_DATA` (отдельная папка данных), `JARVIS_API_KEY` (ключ без
  сохранения), `JARVIS_OPENAI_BASE_URL`, `JARVIS_ELEVENLABS_KEY`, `JARVIS_DEBUG=1` (подробные журналы),
  `JARVIS_SHOW_VOICE=1` (показать скрытое окно голосового движка), `JARVIS_E2E=1`, `JARVIS_AUTO_CONFIRM=allow|deny`.

## Структура проекта

```
├── src/
│   ├── main/            главный процесс Electron
│   │   ├── index.ts     запуск, трей, горячие клавиши, протоколы app:// и jarvis-media://
│   │   ├── app/         окна (главное, HUD-оверлей, скрытое голосовое)
│   │   ├── store/       настройки, зашифрованные ключи, чаты, изображения
│   │   ├── ipc/         мост между окнами и сервисами
│   │   ├── ai/          OpenAI (Responses / Chat Completions), модели Luna/Terra/Sol, речь, ElevenLabs, личность Джарвиса
│   │   └── tools/       управление компьютером: скриншоты, приложения, громкость, файлы, клавиши, мышь, напоминания
│   ├── preload/         безопасный API window.jarvis для окон
│   ├── renderer/
│   │   ├── index.html   главное окно: чаты и настройки (React)
│   │   ├── overlay.html HUD с «реактором»
│   │   ├── voice.html   голосовой движок: микрофон, VAD, слово активации (Whisper в Web Worker), воспроизведение речи
│   │   └── public/      модели VAD / Whisper и wasm onnxruntime (скачиваются npm run assets)
│   └── shared/          общие типы, IPC-контракт, значения по умолчанию, распознавание слова «Джарвис»
├── resources/tray/      значки строки меню / трея (обычные и «слушаю»)
├── build/               иконки приложения, entitlements macOS, скрипт NSIS
├── scripts/             gen-icons.mjs (иконки), fetch-models.mjs (модели)
├── tests/               юнит-тесты (Vitest), tests/e2e — сквозные тесты приложения
├── docs/                SPEC.md (техническая спецификация), USER_GUIDE.md (краткое руководство)
├── electron.vite.config.ts
└── electron-builder.yml упаковка: dmg/zip для macOS, NSIS-установщик для Windows
```
